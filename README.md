# 🚽 Smart Washroom Monitoring System

An IoT + Web based system to monitor washroom usage, cleanliness and complaints in real-time.

## 👩‍💻 Modules
- User Dashboard
- Employee Dashboard
- Admin Panel
- Complaint Management
- Live Sensor Monitoring

## 🔌 Hardware
- ESP8266 NodeMCU
- Ultrasonic Sensor
- Gas Sensor
- Servo Motor

## 💻 Tech Stack
- Node.js + Express
- MongoDB
- Socket.io
- HTML/CSS/JS

## ▶️ How to Run Project

1. Install dependencies
   npm install

2. Start server
   node server.js

3. Open in browser
   https://smart-washroom-system.onrender.com
